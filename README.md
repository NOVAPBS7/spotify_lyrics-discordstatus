# Spotify to Discord Status Synchronizer

A real-time Python application with a modern graphical user interface (GUI) that captures your currently playing Spotify track from Windows and broadcasts the live synchronized lyrics directly to your Discord custom status.

If lyrics are unavailable for a specific track, the application dynamically falls back to an optimized live playback timer.

---

## Features

* **Real-Time SMTC Integration:** Intercepts media states natively from Windows Media Control (SMTC) without requiring a Spotify Developer API account.
* **Smart Synchronization:** Dynamically fetches time-synced `.lrc` lyrics via the LRCLIB API.
* **Dual-Console GUI:** Built with `CustomTkinter`. Features a split-view system:
* **System Log (Left):** Tracks backend execution, network responses, and rate limits.
* **Status Output (Right):** Monitors exactly what text is currently visible to your Discord friends.


* **Intelligent Rate-Limit Protection:** Intercepts Discord HTTP `429 Too Many Requests` responses, automatically reading the `retry_after` header and pausing execution to protect your account.
* **Customization:** Adjustable time offsets (to counter network latency) and custom status emoji support.

## How It Works

The backend operates as an asynchronous polling loop driven by `asyncio` and `threading`:

```
[ Spotify Player ] 
       │
       ▼ (Every 1.0s via Windows SMTC)
[ Windows Media Session Manager ] 
       │
       ▼ (Extracts Artist + Title + Position)
[ Python Core Loop ] ───► Check Cache ───► (If Missing) ───► [ LRCLIB API ]
       │
       ▼ (Matches Timestamp to Status Line)
[ Discord Client Patch Request ] ───► [ Discord User Status ]

```

1. **Extraction:** Every second, the application queries the Windows Global System Media Transport Controls Session Manager to see if a process containing the word "spotify" is actively broadcasting media.
2. **Parsing:** It extracts the track title, artist name, and current playback position in seconds.
3. **Lyrics Matching:** It checks an internal `OrderedDict` cache for the track. If missing, it queries LRCLIB. It then parses timestamps formatted as `[mm:ss.xx]` into matching floating-point seconds.
4. **API Dispatch:** The script matches the track's current timestamp against the lyrics array and updates Discord via an asynchronous HTTP PATCH request.

## The Discord Token: What it is & How to get it

Unlike standard Discord bots that use a dedicated **Bot Token**, this application requires your personal **Discord User Token** (sometimes called a self-token).

### Why is this necessary?

Standard Discord bots cannot modify the custom status (the status text next to an avatar) of a real human user profile. They can only modify their own bot status. To change *your* personal status, the application must interact with the Discord API pretending to be your desktop client.

### How to retrieve your token:

1. Open Discord in your web browser (Chrome, Firefox, or Edge) and log in.
2. Press `F12` or `Ctrl + Shift + I` to open the **Developer Tools**.
3. Navigate to the **Network** tab.
4. Press `Ctrl + R` to reload the page.
5. In the "Filter" search bar, type `/api/v9/users/@me/settings`.
6. Click on the matching network request, navigate to its **Headers** tab, and locate **Authorization** under the *Request Headers* section.
7. Copy the long alphanumeric string. This string is your User Token.

## Security Risks & Warnings

> ⚠️ **CRITICAL WARNING: READ BEFORE RUNNING**
> Utilizing a user token to automate account actions is classified as **Self-Botting** and is a direct violation of **Discord's Terms of Service (ToS)**.

### 1. Risk of Account Suspension

Automated status changes generate a high volume of API traffic. If Discord's automated anti-spam systems flag your token for unnatural activity, your account could face permanent ban or temporary suspension.

### 2. Token Security

Your token is essentially your plaintext password. If someone steals this token, they gain **complete access to your Discord account** without needing your password or 2FA.

* **Never** hardcode your token into public repositories.
* The `config.json` file generated by this application contains your token locally. Treat it with extreme caution.

### 3. Mitigating the Risks (How this App Protects You)

To significantly reduce the footprint of this application, the following defensive features have been built directly into the engine:

* **Adaptive Timer Mode:** If a song lacks lyrics, the app switches to timer mode and scales back requests to **once every 8 seconds** instead of every second. Discord automatically handles the counting smoothly on its end, dropping API usage by 800%.
* **Smart Rate Limiter:** If the script encounters an HTTP `429` error, it immediately freezes all outbound requests for the precise amount of time requested by Discord's servers, eliminating aggressive spam loops.

## Installation & Launch

### Prerequisites

* Windows 10 or Windows 11 (SMTC architecture is exclusive to Windows)
* Python 3.10 or higher

### Step-by-Step Setup

1. Clone the repository and navigate into the project folder:
```bash
cd spotify_lyrics-discordstatus

```


2. Initialize a clean virtual environment:
```bash
python -m venv .venv

```


3. Activate the environment and install the foundational runtime extensions alongside the GUI framework:
```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1

# Now install requirements
.venv\Scripts\pip.exe install customtkinter aiohttp winrt-runtime winrt-Windows.Media.Control winrt-Windows.Foundation winrt-Windows.Foundation.Collections

```


4. Launch the application:
```powershell
.venv\Scripts\python.exe main.py

```
